1. OBJETIVO
======================================================================

Avaliar o que falta para o port/recomp de GTA IV deste repositorio funcionar
com compatibilidade real no Android com SoC MediaTek Helio G99 e GPU ARM
Mali-G57 MC2. O objetivo e compatibilidade e estabilidade primeiro; depois
desempenho sustentado, frametimes, memoria e comportamento termico.

O usuario relata que executou com sucesso no proprio dispositivo Mali-G57
dois outros ports:
- Skate 3 Mobile: https://github.com/Buku313/Skate3-Mobile
- Sonic Unleashed Recompiled Android: https://github.com/SansNope/UnleashedRecomp-Android

Esse relato e evidencia pratica importante de que o dispositivo/driver consegue
executar esses ports, mas ainda NAO prova compatibilidade de GTA IV: engines,
shaders, formatos de textura, extensoes Vulkan, sincronizacao e carga de CPU/GPU
sao diferentes. Nao assumir que o GTA IV usa o mesmo caminho grafico.

O usuario quer que Claude leia esta ficha, analise o codigo real, aponte erros
concretos, oriente as proximas mudancas e priorize correcoes verificaveis.
Nao copiar renderers ou codigo de outros jogos sem necessidade, licenca e
analise semantica. Nao incluir assets, executaveis, chaves ou dados proprietarios

4. FATOS DO CODIGO EXISTENTE INSPECIONADO
======================================================================

- O modulo Android esta em os/android; applicationId/namespace
  com.libertyrecomp; ABI arm64-v8a; minSdk 29; targetSdk 35; compileSdk 35.
- Gradle nao compila CMake: recebe as bibliotecas e recursos staged pelos scripts.
- build_native.sh define CPU_FLAGS="-march=armv8.2-a -fno-emulated-tls".
- O mesmo script passa -DANDROID_PLATFORM=android-28 ao CMake, embora o app
  declare minSdk 29 e o comentario das flags diga que TLS nativo e para API 29+.
  Isso e uma inconsistência que merece verificacao tecnica; nao mudar sem
  confirmar impacto no NDK/toolchain e requisitos de runtime.
- O launcher/proxy tem caminho para escolher o driver Vulkan do sistema. No Mali
  deve-se testar o driver do fabricante Android, nunca assumir Turnip/Adreno.
- O Android e Vulkan-only; documentos do projeto referem Vulkan 1.2, mas o
  manifest declara feature Vulkan 1.1 required. Confirmar no codigo a versao
  efetivamente solicitada e as extensoes/features exigidas; API declarada nao
  garante formatos/extensoes.
- O arquivo os/android/native/CMakeLists.txt cria um proxy chamado vulkan e
  liga libadrenotools; a existencia do proxy nao significa suporte Turnip no Mali.
- O perfil perf.txt existente foi descrito como voltado a hardware Adreno e inclui
  varias das cvars reutilizadas pelo perfil Mali.
- Os scripts de build foram concebidos para Windows + Git Bash e usam ferramentas
  host Windows para shaders.
- Assets de GTA IV nao devem ser incluidos no APK de CI nem no repositorio.
