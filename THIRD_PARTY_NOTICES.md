# Third-party notices and research register

This file records the main projects examined for the Mali-G57 adaptation. It is not a substitute for preserving each dependency's own license and notice files.

- **LibertyRecompAndroid** — https://github.com/vaduur/LibertyRecompAndroid — upstream Android port. Review its repository license and dependency notices before copying any source.
- **LibertyRecomp** — https://github.com/OZORDI/LibertyRecomp — upstream recompilation project. Preserve upstream license and notices.
- **ArkSentinel/LibertyRecompAndroid** — https://github.com/ArkSentinel/LibertyRecompAndroid — experimental Mali research reference. No source patch has been imported solely by virtue of this listing; verify the exact commit and license before reuse.
- **Vulkan specification** — https://registry.khronos.org/vulkan/specs/1.3-extensions/html/ — API reference, not source code incorporated into this repository.
- **Android NDK** — https://developer.android.com/ndk — toolchain documentation.
- **ARM Mali-G57** — https://developer.arm.com/Processors/Mali-G57 — hardware reference.

The repository's `.gitmodules` lists numerous third-party dependencies. Each dependency's license must remain with its source. Before importing code from any external project, add its immutable commit, exact files, license, required notices and local modifications here. No proprietary GTA IV game assets are to be committed or distributed.
